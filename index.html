Everything in the Free Edition

Six core modules to run your WhatsApp Business operations end-to-end — included in the open source self-hosted version.

Automations
Two free nodes ship with the open edition: a Keyword Trigger that listens for incoming WhatsApp keywords, and a Send Message node that fires instant replies in a single linear flow. More node types — conditions, delays, API calls, and branching logic — are actively planned and open for community contributions.

Get Started
in Minutes

Launch your self-hosted WhatsApp CHAT panel in 5 simple commands. Everything is configured using straightforward environments.

WhatsApp Ready | Open Source
terminal — forgechat console
# Waiting for command initiation...
$
01
Clone Repository

Clone the official repository and change the working directory.

git clone
02
Install Dependencies

Install essential node modules and packages.

npm install
03
Configure Environment

Copy .env.example to .env and insert your Meta Cloud credentials.

.env.example to .env
04
Run Database Migrations

Set up database tables and columns with migrations.

npm run db:migrate
05
Launch Developer Server

Run the development server to boot the engine and open local port 3000.

npm run dev

All set. You're ready to build.

Your WhatsApp CHAT backend is up and running. Explore, customize, and scale without limits.
